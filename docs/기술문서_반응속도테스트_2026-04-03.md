# 📘 반응속도 테스트 웹 기술 문서

## 1. 프로젝트 개요
본 프로젝트는 사용자의 반응 속도를 측정하고, 이를 실시간 랭킹 시스템 및 개인 통계 대시보드와 연동하는 웹 애플리케이션입니다. React와 Firebase를 기반으로 하며, 사용자에게 직관적이고 세련된 경험을 제공하는 것을 목표로 합니다.

## 2. 주요 기능 및 로직

### 2.1. 반응 속도 테스트 (Core Logic)
- **라운드 시스템:** 총 3회의 테스트를 거쳐 평균 반응 속도(ms)를 산출합니다.
- **예외 처리:**
  - **부정 출발(Too Early):** 대기 단계(초록색 화면 전)에서 클릭 시 경고 메시지와 함게 라운드를 리셋합니다.
  - **매크로 방지:** 50ms 미만의 비정상적인 속도가 감지될 경우 경고 문구를 출력하고 기록에서 제외합니다.
- **상태 관리:** `idle` → `waiting` → `ready` → `result` 순서로 상태를 관리합니다.

### 2.2. 인증 및 데이터 저장 (Firebase)
- **Google OAuth:** `Firebase Auth`를 통해 구글 로그인을 지원합니다.
- **기록 저장:**
  - `users/{uid}/records`: 모든 플레이 세션의 평균 기록을 타임스탬프와 함께 저장합니다.
  - `rankings/{uid}`: 각 유저별 최고 기록(Best Average)을 1건만 유지하여 리더보드 연산 부하를 최소화합니다.

### 2.3. 리더보드 및 통계
- **글로벌 랭킹:** Firestore의 `orderBy` 쿼리를 사용하여 상위 100위 랭킹을 실시간으로 출력합니다.
- **실시간 백분위:** `getCountFromServer`를 활용해 전체 사용자 수 대비 현재 등수를 동적으로 계산합니다.
- **데이터 시각화:** `Chart.js`를 이용해 최근 10회 기록의 변화 추이를 꺾은선 그래프로 시각화합니다.

## 3. 기술 스택 및 라이브러리
- **Core:** React 19, Vite, React Router v7
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **Styling:** Vanilla CSS (Glassmorphism UI 적용)
- **Charts:** Chart.js, react-chartjs-2
- **i18n:** Context API 기반 다국어 시스템 (KO/EN 지원)

## 4. 데이터 모델 (Firestore)
- **`/rankings` 컬렉션:**
  - `uid` (string): 유저 UID
  - `displayName` (string): 표시 이름
  - `score` (number): 최고 평균 ms
  - `updatedAt` (timestamp): 업데이트 일시
- **`/users/{uid}/records` 컬렉션:**
  - `ms` (number): 평균 속도
  - `createdAt` (timestamp): 생성 일시
  - `device` (string): 기기 종류 (mobile/desktop)

## 5. 디자인 시스템
- **Glassmorphism:** `backdrop-filter: blur()`, `rgba()` 배경을 사용하여 투명하고 세련된 UI를 구현했습니다.
- **CSS Variables:** 테마 컬러와 간격 등을 변수화하여 유지보수성을 높였습니다.
