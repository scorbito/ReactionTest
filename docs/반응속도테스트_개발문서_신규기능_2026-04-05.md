## 기능 1. 결과 공유 카드

### 개요
테스트 결과 화면에서 내 기록을 이미지 카드로 생성하여 SNS에 공유할 수 있는 기능.  
카드에 채널 로고(대단부자)를 포함하여 자연스러운 채널 홍보 효과를 유도한다.

---

### 라이브러리
```bash
npm install html2canvas
```

---

### 카드 디자인 스펙

#### 카드 구성 요소 (위→아래 순서)
1. 상단 로고 영역 — "대단부자 반응속도 테스트" 텍스트 + 채널 아이콘 (있을 경우)
2. 메인 기록 — `230ms` 크게 표시
3. 티어 배지 — 해당 구간 티어명 + 색상 (예: Great / 파란색)
4. 멘트 — 티어별 랜덤 멘트 영문 + 한글 (예: "Sharp! / 집중력이 남다르네요")
5. 부가 정보 — 전국 랭킹 순위 + 상위 백분위 (예: 전국 47위 · 상위 12%)
6. 하단 URL — `reaction-test-danu-777-v2.web.app`

#### 카드 사이즈
- 기본: `1080 x 1080px` (인스타그램 정사각형 기준)
- 내부 ref div는 `540 x 540px` 로 렌더링 후 `scale: 2` 로 캡처 (고해상도 대응)

#### 색상
- 배경: 글래스모피즘 기존 디자인 테마 유지
- 티어별 accent 색상 동일하게 적용
  - Lv.1 Good: `#1D9E75` (teal)
  - Lv.2 Great: `#185FA5` (blue)
  - Lv.3 Excellent: `#BA7517` (amber)
  - Lv.4 INSANE: `#A32D2D` (red)
  - Lv.5 LUCKY: `#534AB7` (purple)

### 구현 상세

#### 카드 컴포넌트
```jsx
// ShareCard.jsx
// - display: none 상태로 DOM에 존재
// - html2canvas 캡처 시에만 visible 처리
// - ref로 캡처 대상 지정

const cardRef = useRef(null);

const handleCapture = async () => {
  const canvas = await html2canvas(cardRef.current, {
    scale: 2,
    useCORS: true,
    backgroundColor: null,
  });
  const imageUrl = canvas.toDataURL('image/png');
  // 이후 다운로드 or 공유 처리
};
```

#### 공유 버튼 동작 흐름
```
[결과 화면]
    └── "공유하기" 버튼 클릭
        ├── html2canvas로 카드 이미지 생성
        ├── navigator.share() 지원 여부 확인
        │    ├── 지원 O (모바일) → Web Share API로 직접 공유 시트 오픈
        │    └── 지원 X (데스크탑) → PNG 파일 자동 다운로드
        └── 완료
```

#### Web Share API 사용 (모바일)
```js
const blob = await (await fetch(imageUrl)).blob();
const file = new File([blob], 'reaction-result.png', { type: 'image/png' });

if (navigator.canShare?.({ files: [file] })) {
  await navigator.share({
    files: [file],
    title: '내 반응속도 기록',
    text: `반응속도 ${ms}ms · 전국 ${rank}위 · 상위 ${percentile}%`,
  });
} else {
  // 데스크탑 fallback — 파일 다운로드
  const link = document.createElement('a');
  link.href = imageUrl;
  link.download = 'reaction-result.png';
  link.click();
}
```

---

### UI 변경사항
- 결과 화면(`result` 상태)에 "공유하기" 버튼 1개 추가
- 버튼 위치: 기존 "다시 하기" 버튼 하단 또는 옆
- 버튼 텍스트: `이미지로 공유하기` (KO) / `Share Result` (EN)
- 카드 컴포넌트는 화면 밖에 렌더링 (`position: absolute; left: -9999px`)

---

### 주의사항
- `html2canvas`는 외부 폰트/이미지 CORS 이슈 발생 가능 → `useCORS: true` 필수
- Firebase Hosting 도메인이므로 CORS 설정 별도 불필요
- 카드 내 이미지(로고 등) 사용 시 같은 도메인 내 파일만 사용할 것

## 기능 2. 디바이스별 분리 랭킹

### 개요
기존 통합 랭킹을 모바일 / 데스크탑으로 분리하여 각각의 리더보드를 제공한다.  
이미 Firestore에 `device` 필드가 저장되고 있으므로 프론트 쿼리 변경만으로 구현 가능.

---

### 현재 데이터 구조 (변경 없음)
```
/rankings/{uid}
  ├── uid: string
  ├── displayName: string
  ├── score: number          // 최고 평균 ms
  ├── updatedAt: timestamp
  └── device: string         // 'mobile' | 'desktop' ← 이미 저장 중
```

---

### 구현 상세

#### Firestore 쿼리 변경
```js
// 기존 — 전체 랭킹
const q = query(
  collection(db, 'rankings'),
  orderBy('score', 'asc'),
  limit(100)
);

// 변경 — 디바이스 필터 추가
const q = query(
  collection(db, 'rankings'),
  where('device', '==', deviceType), // 'mobile' | 'desktop' | 'all'
  orderBy('score', 'asc'),
  limit(100)
);
```

#### Firestore 복합 인덱스 추가 필요
```
컬렉션: rankings
인덱스: device (ASC) + score (ASC)
```
Firebase 콘솔 → Firestore → 인덱스 탭에서 수동 추가 또는  
쿼리 실행 시 콘솔 오류 링크로 자동 생성 가능.

#### 디바이스 감지 유틸
```js
// utils/getDeviceType.js
export const getDeviceType = () => {
  return /Mobi|Android|iPhone|iPad/i.test(navigator.userAgent)
    ? 'mobile'
    : 'desktop';
};
```

---

### UI 변경사항

#### 랭킹 화면 상단에 탭 추가
```
[ 전체 ] [ 모바일 ] [ 데스크탑 ]
```
- 기본 선택: `전체`
- 탭 전환 시 해당 device 필터로 Firestore 재쿼리
- 로딩 중 스켈레톤 또는 기존 데이터 유지

#### 내 순위 표시 변경
- 탭에 따라 현재 탭 기준 내 순위 및 백분위 재계산
- 예: "모바일 전국 12위 · 상위 8%"

#### 다국어 처리 (i18n)
```js
// 기존 i18n Context에 추가
{
  ko: {
    tab_all: '전체',
    tab_mobile: '모바일',
    tab_desktop: '데스크탑',
  },

    tab_desktop: 'Desktop',
  }

```

---

### 데이터 마이그레이션 고려사항
- 기존 `rankings` 도큐먼트 중 `device` 필드가 없는 레코드 존재 가능
- `where('device', '==', 'mobile')` 쿼리 시 해당 레코드는 자동 제외됨
- `전체` 탭은 기존처럼 device 필터 없이 쿼리하면 해결됨 → 별도 마이그레이션 불필요
